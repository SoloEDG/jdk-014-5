# PANEL

安装：`npm install`

本地启动：`npm run dev`

生产构建：`npm run typecheck && npm run build`

Docker 启动：`docker compose up --build`，访问 http://localhost:3014。

## 双机编辑与离线合并

同一部漫画可以在两台电脑上分别编辑，再通过作品文件合并回来，全程无需联网。

**基本流程**

1. 在左栏「作品同步」点击 **导出作品文件**，把 `.panel.json` 文件拷到另一台电脑；
2. 对方 **导入并合并** 后内容一致，即加入同一同步线，之后各自离线编辑；
3. 任何一方再导出、另一方导入，即可对照**共同起点**做三向合并。

**合并时能看见什么、决定什么**

- 导入前逐项列出双方的新增、删除与修改，冲突（同一字段两边都改、一边删页一边在该页加书签、双方不同重排等）必须人工选择后才能应用；
- 不冲突的修改自动合并：一边重排页面、另一边改对白，两者都保留；
- 可按章批量选择「本章用我的 / 用对方的」，底部实时预览代价（增删页数、修改数、体积变化、将放弃哪边的几处工作）；
- 一边删页、另一边在该页加了书签时，会列为冲突由你决定，书签不会被静默丢弃；
- 复制出的页面、替换过图片的页面都按独立身份处理，不会被误判为同一对象；双方各自导入同一张图片时给出「疑似重复」提示，可选择不重复添加；
- 合并后阅读位置、声景与书签统一指向同一组有效身份；重复导入同一文件不会产生重复素材；
- 合并后可 **撤回上次合并** 整次回退；若浏览器存储空间不足导致保存失败，可直接 **下载合并结果**，工作成果不丢失。

**页面与分镜编辑**

右栏「编辑当前页」支持：页面前移/后移、复制本页、替换图片、删除本页，以及当前分镜的角色、对白、音效、时长编辑——两台电脑上的分歧修改正是合并的对象。

点击「生成分支文件体验合并」可模拟另一台电脑的修改：先生成分支文件，再在本机做几处修改，最后导入该文件即可体验完整合并流程。
